# RosCar 持续维护

远端：https://github.com/JTwilliam/RosCar.git 。提交主题按约定使用[Ubuntu主机上传]前缀；正文说明真实编辑/验证环境，不把WSL模拟当实车。

## 每次更新

在对应机器先停止受影响节点、保留本地修改，再执行：

```bash
cd ~/RosCar
git status --short
git pull --ff-only origin main
```

然后按机器选择：

- Ubuntu Desktop上位机：进入host_ws，运行 `bash build.sh`；启动按[上位机README](../host_ws/README.md)。
- 树莓派：进入pi_ws，运行 `bash build.sh`；启动按[树莓派README](../pi_ws/README.md)。

旧lidar_ws不再构建，源码已迁到pi_ws/src。不要在仓库根目录colcon build，也不要用另一主机的build/install。新构建输出host_runtime/pi_runtime避开旧缓存；旧产物和本地配置不自动删除。新终端不要自动source旧overlay。

## 配置与提交

host_ws/host.env、pi_ws/pi.env为机器本地配置，不提交。源码改动检查Git状态及远端，保留用户工作；运行适用验证后仅提交相关源码文档，正常推送，不强推，不提交build/install/log。网络或认证失败时保留本地提交并说明。

Git/GitHub凭据由本机工具管理，不在聊天索要密码或令牌。维护约定不代表自动定时提交。
