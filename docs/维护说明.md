# RosCar 持续维护

远端：https://github.com/JTwilliam/RosCar.git

Ubuntu 主机提交主题使用 **[Ubuntu主机上传]** 前缀，提交正文记录内容和实际验证。本仓库是后续源码来源，旧散落目录作为迁移前副本保留。

## 开发约定

检查仓库 Git 状态、当前分支和远端更新，保留未提交工作；改动仓库源码并更新对应文档，运行适用验证后提交并正常推送。不要强制推送或提交构建产物。网络或认证失败时保留本地提交并如实报告。

本约定用于后续开发任务，不自动定时提交未经检查的文件。

## 树莓派部署

首次：

```bash
git clone https://github.com/JTwilliam/RosCar.git ~/RosCar
```

更新已有部署，先停止相关节点并处理本地未提交改动：

```bash
cd ~/RosCar
git status --short
git pull --ff-only
source /opt/ros/humble/setup.bash
cd ~/RosCar/pi_ws
colcon build --symlink-install --packages-select learm_bridge icm20948_ros2
```

更新雷达时：

```bash
source /opt/ros/humble/setup.bash
cd ~/RosCar/lidar_ws
colcon build --symlink-install --packages-select ldlidar --cmake-args -DBUILD_TESTING=OFF
```

推荐使用仓库内工作区。若继续沿用旧 ~/pi_ws、~/lidar_ws，需要主动同步源码，并统一所有终端 source 路径，避免运行旧副本。

## 认证

首次推送需要 Ubuntu 主机的 GitHub 写入凭据，通过本机 Git/GitHub CLI 完成登录。不要把密码、令牌或私钥放入仓库或聊天。提交主题的主机标记与 GitHub 登录身份是独立信息。
